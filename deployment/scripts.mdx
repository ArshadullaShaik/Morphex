Morphex ships with a full set of Hardhat scripts for compiling, testing, deploying, and operating the protocol. This page groups every command by purpose so you can find the right script quickly.

## Build and test

| Command | Purpose | Notes |
| --- | --- | --- |
| `npm run compile` | Compile Solidity contracts with Hardhat. | Uses Solidity 0.8.27, viaIR, Cancun EVM. |
| `npm test` | Run the full Hardhat test suite. | Targets the in-memory Hardhat network with mock FHE. |
| `npm run typecheck` | Type-check the TypeScript sources. | Runs `tsc --noEmit`. |
| `npm run lint:sol` | Lint Solidity with Solhint. | Checks everything under `contracts/**/*.sol`. |
| `npm run clean` | Remove Hardhat cache and artifacts. | Also cleans the frontend `dist` folder. |

## Local development

| Command | Purpose | Notes |
| --- | --- | --- |
| `npm run node` | Start a local Hardhat node. | Runs on `http://127.0.0.1:8545` with chain ID 31337. |
| `npm run deploy:local` | Deploy core contracts to the local node. | Writes `frontend/.env.local`. |
| `npm run deploy:relayer-local` | Deploy the full relayer pair setup locally. | Includes mock tokens and vault. |
| `LOCAL_USER=0x... npm run faucet:local` | Mint local test tokens to a specific address. | Requires the local deployment to exist. |

## Sepolia deployment

| Command | Purpose | Notes |
| --- | --- | --- |
| `npm run deploy:sepolia` | Deploy core Morphex contracts to Sepolia. | Writes `frontend/.env.local`. |
| `npm run deploy:sepolia:core` | Deploy core plus mock tokens for USDC/USDT. | Shorthand for `DEPLOY_MOCK_TOKENS=1` with the relayer pair script. |
| `npm run deploy:relayer-pair` | Deploy the full relayer pair and vault to Sepolia. | Writes both `.env.local` and `.env.relayer.local`. |
| `npm run verify:sepolia` | Verify deployed contracts on Etherscan. | Requires `ETHERSCAN_API_KEY`. |

## Sepolia operations

| Command | Purpose | Notes |
| --- | --- | --- |
| `npm run faucet:sepolia` | Distribute test tokens from the owner account. | Requires the owner to hold the initial confidential supply. |
| `MORPHEX_TOKEN_ADDRESS=0x... MORPHEX_RECIPIENT=0x... MORPHEX_AMOUNT=10000 npm run mint:testnet` | Mint a specific amount of a testnet token to a recipient. | Uses the token owner account. |
| `npm run mint:confidential` | Mint confidential balances directly via encrypted input. | Uses the Hardhat CLI FHE API. |
| `npm run deposit:usdt` | Deposit public USDT into the relayer vault. | Prepares tokens for confidential wrapping. |
| `npm run relayer:process-deposits` | Process pending vault deposits off-chain. | Relayer worker script. |
| `npm run relayer:daemon` | Run the relayer as a long-lived daemon. | Watches for new deposits and fulfills them. |
| `npm run fulfill:withdrawal` | Fulfill a pending withdrawal request. | Relayer fulfills an escape-hatch or normal withdrawal. |
| `npm run seed:liquidity` | Add deep liquidity to deployed pairs. | Useful for testing swaps with low slippage. |
| `npm run test:swap` | Execute a private swap against Sepolia. | End-to-end script that encrypts inputs and submits. |
| `npm run check:balances` | Read and display balances for the deployer account. | Helps verify token state after operations. |
