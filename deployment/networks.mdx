Morphex supports two networks: a local Hardhat environment for rapid iteration and the Sepolia testnet for end-to-end confidential operations with the live Zama infrastructure. Choose the network that matches your current task.

## Hardhat (default)

- **Chain ID:** 31337
- **RPC:** `http://127.0.0.1:8545`
- **FHE mode:** Mock FHE. No real coprocessor, relayer, or KMS is involved.
- **Use for:** Running the test suite, local contract debugging, and frontend development against a fast, resettable chain.

Start the node with `npm run node`, then deploy with `npm run deploy:local` or `npm run deploy:relayer-local`.

## Sepolia

- **Chain ID:** 11155111
- **RPC resolution order:**
  1. `SEPOLIA_RPC_URL` from environment
  2. Alchemy (`https://eth-sepolia.g.alchemy.com/v2/${ALCHEMY_API_KEY}`)
  3. Infura (`https://sepolia.infura.io/v3/${INFURA_API_KEY}`)
  4. Public fallback (`https://ethereum-sepolia.publicnode.com`)
- **Accounts:** Loaded from `PRIVATE_KEY` or `MNEMONIC`. Falls back to the Hardhat test mnemonic if neither is set.
- **Use for:** Real confidential swaps, balance decryption, and relayer integration.

Deploy with `npm run deploy:sepolia` or `npm run deploy:relayer-pair`, then start the frontend and switch your wallet to Sepolia when prompted.

## Solidity compiler

Morphex contracts compile with the following Hardhat settings:

- **Version:** `0.8.27`
- **Optimizer runs:** `200`
- **viaIR:** `true` (required because FHE circuits are stack-heavy)
- **EVM version:** `cancun`

## fhEVM plugin

The `@fhevm/hardhat-plugin` injects `hre.fhevm` into the Hardhat runtime. Scripts that create encrypted inputs outside the test runner must call `await fhevm.initializeCLIApi()` first. Both `scripts/deploy.ts` and `scripts/deploy-relayer-pair.ts` include this call before any encrypted input is created.

<Note>
  Only Sepolia has the live Zama relayer and KMS. The mock Hardhat network cannot perform real `userDecrypt` calls, so confidential balance decryption and private swaps against the relayer will fail locally.
</Note>
