Morphex uses the Zama fhEVM relayer SDK to encrypt values inside the browser before they ever reach the chain. This page shows how to initialize the SDK once, encrypt a single `uint64` amount, and submit it through the `submitPrivateSwap` helper.

## SDK initialization

The Zama web SDK needs two WASM assets: one for TFHE and one for the KMS. Import them with a Vite `?url` suffix so the bundler copies them into `dist`, then call `initSDK` with those paths. After initialization, create an FHEVM instance bound to the user's wallet.

```typescript
import { createInstance, initSDK, SepoliaConfigV2 } from '@zama-fhe/relayer-sdk/web';
import tfheWasmUrl from '../node_modules/@zama-fhe/relayer-sdk/lib/tfhe_bg.wasm?url';
import kmsWasmUrl from '../node_modules/@zama-fhe/relayer-sdk/lib/kms_lib_bg.wasm?url';

await initSDK({ tfheParams: tfheWasmUrl, kmsParams: kmsWasmUrl });
const fhevm = await createInstance({ ...SepoliaConfigV2, network: window.ethereum });
```

<Note>
  `initSDK` is a one-shot operation. The Morphex app caches the returned promise in `sdkInitialization` so every subsequent call reuses the same initialized state.
</Note>

## Single-value encryption

To encrypt an amount that a specific contract will later verify, bind the input to the target contract address and the user's own address. This prevents replay across different contracts or users.

```typescript
const encrypted = await fhevm
  .createEncryptedInput(pairAddress, userAddress)
  .add64(amountIn)
  .encrypt();
// encrypted.handles[0], encrypted.inputProof
```

The returned object contains:

- `handles[0]`: the encrypted handle (`bytes32`) you pass to the contract
- `inputProof`: the ZK proof the contract needs to validate the ciphertext

## Submit a private swap

Before the pair can move tokens on the user's behalf, the user must authorize it as an operator with an expiry. Then both the input amount and the output target are encrypted and passed to `swapExactInput`.

```typescript
export async function submitPrivateSwap(
  signer: JsonRpcSigner,
  address: string,
  amountIn: bigint,
  amountOutTarget: bigint,
  sellTokenAddress: string,
  buyTokenAddress: string,
) {
  if (!hasContractConfig()) throw new Error('Deploy the Sepolia testnet contracts before swapping.');
  if (config.chainId !== TESTNET_CHAIN_ID) {
    throw new Error('Private swaps require a Sepolia deployment with the Zama relayer.');
  }
  await useConfiguredNetwork();
  await initializeFheSdk();
  const fhevm = await createInstance({ ...SepoliaConfigV2, network: getEthereum() });
  const pairAddress = deployedPairs[pairKey(sellTokenAddress, buyTokenAddress)] || config.pairAddress;
  const pair = new Contract(pairAddress, pairAbi, signer);
  const pairToken0 = await pair.token0();
  const inputToken = new Contract(sellTokenAddress, erc7984Abi, signer);
  const direction = pairToken0.toLowerCase() === sellTokenAddress.toLowerCase();
  await (await inputToken.setOperator(pairAddress, Math.floor(Date.now() / 1000) + 3600)).wait();
  const encryptedInput = await fhevm.createEncryptedInput(pairAddress, address).add64(amountIn).encrypt();
  const encryptedOutput = await fhevm.createEncryptedInput(pairAddress, address).add64(amountOutTarget).encrypt();
  return pair.swapExactInput(direction, encryptedInput.handles[0], encryptedOutput.handles[0], encryptedInput.inputProof, encryptedOutput.inputProof);
}
```

The `setOperator` call grants the pair permission to call `confidentialTransferFrom` on the sell token. The one-hour expiry limits the window of that permission. The pair checks the encrypted output target privately and refunds the input when the target is stale or too high.
