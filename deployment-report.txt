4. ROOT CAUSE ANALYSIS: WHY RENDER BOT DID NOT PROCESS DEPOSITS
--------------------------------------------------------------------------------
1. MISSING PRIVATE_KEY IN RENDER ENVIRONMENT:
   .env is in .gitignore, so Render builds without your local .env. In
   hardhat.config.ts, when PRIVATE_KEY is undefined, Hardhat defaults to a mock
   mnemonic whose address (0xf39F...) does not own RELAYER_ROLE on Sepolia.
   As a result, the daemon logs '[SKIP] Signer lacks RELAYER_ROLE' and rejects
   all incoming deposits.

2. RENDER FREE TIER IDLE SLEEP:
   Render's free Web Services automatically shut down after 15 minutes of zero
   inbound HTTP requests. While the script runs an HTTP health check on port
   10000, Render requires external web traffic to remain active. Once asleep,
   the daemon stops polling Sepolia blocks.

3. 500 BLOCK SEARCH WINDOW LIMIT:
   In scripts/relayer-daemon.ts:
   `vault.queryFilter(filter, Math.max(0, currentBlock - 500))`
   500 blocks on Sepolia equals ~100 minutes. If Render restarts or wakes up
   after being idle, any deposit older than 100 minutes is permanently excluded
   from the query filter.

4. COMMAND TYPOS / INVOCATION SYNTAX:
   The command `npx relayer:demon` triggers an npm error (EUNSUPPORTEDPROTOCOL).
   The correct start command is: `npm run relayer:daemon`.


5. WHY cUSDT WAS NOT VISIBLE IN FRONTEND
--------------------------------------------------------------------------------
1. ENCRYPTED BALANCE (ERC-7984):
   Unlike standard ERC-20 tokens, confidential tokens store balances as
   encrypted 32-byte ciphertext handles (confidentialBalanceOf). MetaMask and
   Etherscan cannot show standard numerical balances.

2. EIP-712 DECRYPTION SIGNATURE:
   In the Morphex UI, the user must connect their wallet and sign an EIP-712
   typed data authorization message, allowing the Zama KMS web client to decrypt
   and display the plaintext number.

3. LOCALHOST VS SEPOLIA ENV CONFLICT:
   Running `npm run deploy:relayer-local` overwrote `frontend/.env.local` with
   Chain ID 31337 (Localhost) and local contract addresses. Because Vite
   prioritizes .env.local over .env.production, local dev servers were
   querying the Hardhat local node instead of Sepolia.
